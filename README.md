# 🧠 Assignments & Notes Hub
A clean and minimal web platform designed for students to manage assignments, notes, and attendance in one place. Built during a college hackathon as a practical tool to simplify daily academic workflow.
---
## 📌 Overview
Assignments & Notes Hub allows students to browse, search, upload, and download study materials by subject, while giving instructors a simple QR-code-based way to track attendance. The goal is to create a unified system that saves time, improves accessibility, and keeps things organized — all through a simple, responsive UI.
---
## 🚀 Features
- Browse and search notes/assignments by subject  
- Upload notes — they appear instantly in the Notes Library  
- Download notes and assignments with one click  
- QR-code based attendance with live tracking and CSV export  
- Dark mode with saved preference  
- Responsive design for all devices  
- Simple, distraction-free interface

## 🔍 How It Works
- **Notes & Uploads**: Notes are organized by subject. Uploading a file saves it locally and instantly adds it to the matching subject's list in the Notes Library.  
- **Search**: Typing in the search bar filters both subject cards and notes in real time.  
- **Attendance**: Start a session to generate a one-time QR code, simulate student check-ins, view the live list, and export everything as a CSV.  
- **Login**: Gated access to Upload and Attendance — this is a demo login, so any username/password works.
